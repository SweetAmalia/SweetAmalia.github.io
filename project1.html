Building website portfolio

A simple project that respresents my skills, projects and personality as an IT student.

September 2026

Overview & Preview

This video showcase demonstrates the fluid layout and interactive portfolio search filtering in real time across dynamic desktop.

1. Planning & Design Architecture

The project began with structured mockups and wireframes to establish a clean, user-centric interface. Key design principles focused on high contrast readability, fluid typography scales, and visual balance across desktop and mobile devices.

Semantic HTML5 elements were chosen from the ground up to guarantee strong accessibility, clear document structure, and effortless navigation for screen readers and search engines.

2. Technical Development & Implementation

Building the layout required modern CSS3 techniques including Flexbox for header and card alignment, coupled with CSS Grid for robust two-column layouts. Responsive breakpoints were calibrated using clamp typography and relative units.

JavaScript features were integrated to dynamically render projects from structured data, allowing real-time client-side search filtering, category selection, and custom sorting without page reloads.

3. Optimization, Accessibility & Key Takeaways

Cross-browser performance was optimized by streamlining styling rules, minimizing asset sizes, and using native semantic markup. Accessibility standards like proper ARIA attributes, semantic landmarks, and keyboard navigation were thoroughly tested.

This project strengthened core frontend fundamentals, demonstrating how pure HTML5 and vanilla JavaScript can produce fast, fully accessible, and highly responsive web applications.
